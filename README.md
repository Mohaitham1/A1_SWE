# A1_SWE

Software Engineering Assignment 1 — Faculty of Computers and Artificial Intelligence, Cairo University.

Java console programs from coursework:

| Program | What it does |
| --- | --- |
| Balance tracker | Budget vs. category expenses, with remaining-balance warnings |
| Currency and gold exchange | Conversion utilities |
| Daily expense | Day-level expense logging |
| Roll dice | Simple dice roller |

## Run

```bash
javac *.java
```

Then start the class you want (each file currently declares `public class Main` — compile and run one at a time).
